# System Patterns

2026-07-14 - Memory Bank initialized.

## Coding Patterns

*   **Vite project structure** — `public/` for static output, source in root
*   **Vanilla JS** — no React/Vue framework
*   **SQL parsing in client-side JS** — regex-based formatter
*   **CSS custom properties** — dark theme via `:root` variables

## Architectural Patterns

*   **SPA tool page** — single page app, no routing
*   **Git-push deployment** — CF Pages auto-build from git
*   **SEO-first** — every page with unique title/meta/JSON-LD

## Testing Patterns

*   Manual testing only
*   GSC console monitoring for errors
