What Actually Matters in a SQL Formatter

When evaluating SQL formatters, these are the criteria that make a real difference in daily use:

  1. Privacy: Does the formatter send your SQL to a server? If yes, it is not suitable for production queries. Client-side processing is non-negotiable.
  2. Dialect support: MySQL, PostgreSQL, T-SQL, and PL/SQL have different quoting and syntax rules. A formatter that only handles 'Standard SQL' will mangle dialect-specific code.
  3. Speed: Server-based formatters add network latency. Large queries (1000+ lines) can take several seconds. Client-side formatting is instant.
  4. No paywalls: Query size limits, format-per-day caps, or 'premium features' that are actually basic functionality are common dark patterns.
