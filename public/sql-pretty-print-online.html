SQL Pretty Print Online

When you need to put a SQL query in documentation, a pull request description, or a Slack message, raw unformatted SQL is embarrassing. It screams 'I didn't have time to make this readable' — which might be true, but you don't need to advertise it.

SQL pretty print solves this in one click. Paste the query, hit format, and you get output that looks like it came from a style-guide-compliant codebase. Consistent capitalization, logical line breaks, and clean indentation that makes the query actually pleasant to read.

I keep this tool bookmarked specifically for code reviews. When someone posts a messy query in a PR, I format it before trying to understand the logic. It saves about five minutes of mental parsing per review, which adds up fast.
