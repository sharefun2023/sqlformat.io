Syntax Highlighting: Every Token Gets Its Color

The free online SQL pretty printer tokenizes your formatted SQL and assigns a distinct color to each type of token:

  • Keywords (SELECT, FROM, WHERE, JOIN, GROUP BY, etc.) — rendered in a distinct red/pink tone in both dark and light themes
  • Functions (COUNT(), SUM(), COALESCE(), ROW_NUMBER(), etc.) — purple/violet coloring for immediate recognition
  • String literals — blue tones to distinguish data values from structure
  • Numbers — bright blue for easy spotting in queries with LIMIT, OFFSET, or WHERE clauses
  • Comments (-- single line, /* block */) — italic and muted gray to de-emphasize notes
  • Operators (AND, OR, IN, BETWEEN, LIKE) — orange/amber to highlight logical connections

Choose between Dark Theme (GitHub-style dark background, ideal for developer screens and modern docs) and Light Theme (white background, perfect for print, publications, and formal documentation).

Export Formats: PNG vs SVG

The SQL pretty printer supports two export formats, each suited to different use cases:

  • PNG Export — Raster image format, good for social media, screenshots, and embedding in documents where a fixed-resolution image is fine. The SQL is rendered onto an HTML5 Canvas element with exact pixel positioning.
  • SVG Export — Vector image format, best for professional documentation, print, and any use case requiring resolution independence. SVG images scale perfectly to any size without quality loss. Each character is an individual text element with its own color, producing crisp output at any zoom level.
